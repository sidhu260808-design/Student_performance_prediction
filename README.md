# Student_performance_prediction

## Project Overview
Student Performance Prediction is a Machine Learning-based web application developed using Python and Streamlit. It predicts students' final marks based on different academic and personal factors.

## Objectives
- To predict students' final academic marks.
- To analyze factors affecting student performance.
- To use Machine Learning for performance prediction.
- To provide a simple and user-friendly interface.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Machine Learning (Linear Regression)

## Features
- Interactive student information form.
- Prediction of final marks.
- Student performance analysis.
- Model performance evaluation.
- Dataset preview and information.
- User-friendly navigation.

## Dataset
The project uses a CSV dataset named `students.csv` containing student information and academic performance details.

## Machine Learning Algorithm
Linear Regression is used to train the model and predict students' final marks.

## How to Run the Project

1. Install the required libraries:

   `pip install streamlit pandas numpy scikit-learn`

2. Run the application:

   `streamlit run app.py`

3. Open the local URL displayed in the terminal.
